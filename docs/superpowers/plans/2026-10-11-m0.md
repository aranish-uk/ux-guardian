# M0 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, task by task.

**Goal:** Establish the M0 Python foundation and deployable three-journey demo.

**Architecture:** Adapt the upstream bounded swarm around a vendor-neutral agent
protocol. Use fixture replay for the CLI; keep paid live execution gated for M1.
The independent Next.js demo uses environment-only seeded authentication.

**Tech Stack:** Python 3.12, uv, pytest, Ruff, Pyright, Pydantic, Typer, Next.js, pnpm.

**Spec:** docs/superpowers/specs/2026-10-11-m0-design.md

## Global constraints
- Python entry points and pathlib for cross-platform developer tooling.
- No secrets in tracked files, logs, fixtures, or screenshot captions.
- No live TinyFish calls in tests; only permitted vendor modules import its SDK.
- M0 only; no Action publishing, intelligent diff analysis, or live agent integration.

## Review focus
- Missing seeded credentials must refuse login rather than accept arbitrary users.
- A COMPLETED agent status alone must not make a failed journey pass.
- Budget, URL, manifest and command validation must fail safely.
- Fixture replay must not contact supplied URLs or produce a paid run.
- Payment must remain unsubmitable and unknown product routes must return 404.
