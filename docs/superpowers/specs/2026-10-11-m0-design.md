# M0 foundation design

Approved in chat on 2026-10-11. Authority: PRD sections 5–11 and AGENTS.md.

Preserve vibetest-use's Git history, rename its package to ux_guardian, remove
browser-use and Google-specific dependencies, and retain attribution in NOTICE
and README. Adapt its semaphore/gather swarm to the BrowserAgent protocol and
journey manifest. Keep the optional MCP interface for fixture replay only.

Use Python 3.12, uv, pathlib, Pydantic and Typer. CLI run --dry-run replays saved
synthetic evidence, without network or secrets. CLI live journey shows the cost
and confirmation gate, but fails explicitly because live TinyFish is M1. Do not
claim that the later production pipeline exists. Add the mandatory judge truth
table, severity and markdown contract tests as foundational pure functions;
real acquisition, diff intelligence and GitHub publishing remain later milestones.

The demo is a small Next.js storefront with login, account dashboard, search,
product, cart and address-to-stub-payment flows. Only environment-provided seeded
credentials work; no credentials are committed, printed, or captured in evidence.
Authentication fails closed when credentials are missing. Payment cannot submit.
Use signed expiring HttpOnly cookies and an origin check for the login endpoint.

Verify pytest, Ruff, Pyright, Next build/typecheck and desktop/mobile browser
smoke tests. Deploy to a new demo Vercel project when authentication is available;
production and preview must both load before M0 is marked complete. Document
any external blocker without fabricating URLs. One milestone branch, no main push.
